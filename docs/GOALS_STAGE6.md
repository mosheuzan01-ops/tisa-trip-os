- מה קורה בכל יום בטיול?

## מה נכנס (רק מה שאושר)
1. **לוח שנה כרשימת ימים.** יום לכל תאריך בין תחילת הטיול לסופו. בכל יום: התחנה, המעברים, המשימות, הצ'ק-אין, והסכום המתוכנן ליום. לא רשימת ההוצאות המלאה.
2. **יומן.** הערה אחת לכל יום, לפי תאריך. ליד ההערה מוצג היעד של אותו יום. בלי תמונות.
3. **צ'ק-אין לטיסות ולמלונות.** הזנה ידנית. תזכורת בתוך האפליקציה בלבד, בלי push. מה שלא הוזן מוצג "עוד לא הוזן", בלי ניחוש.
4. **משקל מזוודה.** המשתמש קובע את המגבלה. האפליקציה מסכמת את המשקל ומזהירה כשעוברים אותה. אין מגבלה מוכנה של חברת תעופה.
5. **הפרשי שעות.** ישראל מול תאילנד, מחושב מאזורי הזמן של המכשיר (`Asia/Jerusalem`, `Asia/Bangkok`). אין הפרש קבוע בקוד.

## מבנה הנתונים (גרסה 4)
**יומן** (`trip.journal`, שדה חדש, אובייקט):
```
{ "YYYY-MM-DD": { note, updatedAt } }
```
- הערה ריקה נמחקת מהאובייקט, ולא נשמרת כמחרוזת ריקה.
- היעד לא נשמר בהערה. הוא מחושב מהמסלול לפי התאריך, כך ששינוי במסלול מתעדכן לבד.

**צ'ק-אין** (`trip.checkins[i]`, שדה חדש):
```
{ id, kind, title, transferId, stopId, date, time, zone, booking, link, note, done }
```
- `kind`: `flight` או `hotel`.
- `transferId`: רק לטיסה, ורק אם המשתמש בחר טיסה קיימת ממסך הטיסות והמעברים. אחרת `null`.
- `stopId`: רק למלון, ורק אם המשתמש בחר תחנה. אחרת `null`.
- `date`, `time`: מתי הצ'ק-אין (לטיסה: מתי נפתח הצ'ק-אין. למלון: מתי מגיעים). `date` חובה, `time` רשות. בלי שעה מוצג "שעה: עוד לא הוזנה".
- `zone`: `Asia/Jerusalem` או `Asia/Bangkok`, לפי מה שהמשתמש בחר. ברירת המחדל: `Asia/Bangkok`.
- `link`: רק אם מתחיל ב-`http://` או `https://`, כמו ב-0.5.3.
- אין שעת פתיחה מחושבת (למשל "24 שעות לפני הטיסה"). רק מה שהמשתמש הזין.

**מזוודה** (`trip.luggage`, שדה חדש):
```
{ bags: [ { id, name, limitGrams, items: [ { id, name, grams } ] } ] }
```
- משקל נשמר בגרמים, כמספר שלם (כמו כסף באגורות). ההזנה בק"ג, עד 3 ספרות אחרי הנקודה.
- `limitGrams`: `null` עד שהמשתמש קובע. בלי מגבלה מוצג "עוד לא נקבעה מגבלה", ואין אזהרה.

**המרה מ-3 ל-4:** מוסיפים `journal: {}`, `checkins: []` ו-`luggage: { bags: [] }`. שום נתון אחר לא משתנה. גם גיבוי מגרסה 3 נטען. השדה הריק `events` נשאר כמו שהוא.

## הגדרות
- **ימי הלוח:** כל תאריך מ-`startDate` עד `endDate`, כולל שניהם. בלי תאריכי טיול מוצג "עוד אין תאריכי טיול", עם קישור להגדרה.
- **התחנה של יום:** כמו במסלול. ביום מעבר מוצגות שתי התחנות, היוצאת והמגיעה.
- **המעברים של יום:** לפי התאריך שלהם, ממוינים לפי שעה. בלי שעה: "שעה: עוד לא הוזנה".
- **המשימות של יום:** משימות שתאריך היעד שלהן הוא אותו יום. משימה באיחור מסומנת לפי שעון בנגקוק, כמו בשלב 5.
- **הסכום המתוכנן ליום:** סכום ההוצאות שתאריכן הוא אותו יום ושהסטטוס שלהן "מתוכנן" או "התחייבות עתידית", בשקלים, לפי השער שנשמר בכל הוצאה. "שולם" לא נכלל, כדי שלא תהיה כפילות ולא יתבלבל החישוב של "פנוי אחרי התכנון". מה ששולם רואים במסך הכסף. (סטטוס "בוטל" לא קיים היום במבנה הנתונים. אם יתווסף בעתיד, גם הוא לא ייכנס לסכום.) בלי הוצאות כאלה מוצג "אין תכנון ליום זה".
- **היום:** לפי שעון בנגקוק. היום הנוכחי מסומן, והמסך נפתח עליו כשהוא בתוך הטיול.
- **תזכורת צ'ק-אין:** צ'ק-אין שלא סומן "בוצע", והתאריך שלו הוא היום או עבר (לפי אזור הזמן שהוזן). מוצגת בכרטיס הבית, אצל העוזר ("היום"), ובלוח השנה. לא נשלחת התראה מחוץ לאפליקציה.
- **הפרש שעות:** מחושב לתאריך מסוים, דרך `Intl.DateTimeFormat`, כי בישראל יש שעון קיץ ובתאילנד אין. מוצג כ"תאילנד מקדימה את ישראל ב-X שעות" עם X שמחושב בזמן ריצה. ליד שעת צ'ק-אין מוצגת גם השעה באזור השני. אם המכשיר לא מכיר את אזור הזמן: "לא זמין במכשיר הזה", בלי מספר.
- **משקל מזוודה:** סכום המשקלים של הפריטים בתיק. "חריגה" רק כשהסכום גדול מהמגבלה. שווה למגבלה זה לא חריגה. האזהרה באדום כהה ועדין, כמו חריגה בשלב 4, ומציגה בכמה עברו.
