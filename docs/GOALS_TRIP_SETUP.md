## מטרה (משפט אחד)
המשתמש קובע תאריכי טיול ותקציב מתוך מסך הבית. הנתונים נשמרים רק במכשיר, ומסך הבית מתעורר לחיים: ספירה לאחור, "יום X בטיול" והתקציב בגב הכרטיס.
