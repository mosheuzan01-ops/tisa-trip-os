## מה נמצא ותוקן בזמן הבדיקות
- **מדיניות `trips_select`:** בלי `owner_id = me`, יצירת טיול נכשלה. נמצא ב-RLS המקומי.
- **העותק המדויק של הנתונים:** נשמר עכשיו לפני הורדת הגיבוי.
- **הצעת ההעברה:** מופיעה רק בטלפון הראשון של החשבון.
- **`stage9-brand-browser`:** ציור דף הראיות של האייקונים עבר לדף נפרד. ה-CSP של האפליקציה דחה, בצדק, את הסגנונות שבתוכו.
- **רשומה גדולה מ-1MB:** נשארת בטלפון ולא חוסמת את השאר.
