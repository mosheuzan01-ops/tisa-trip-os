# GOALS: שלב 11, מידע וחירום (0.10.0)

**מטרה:** מסך "מידע וחירום" שעובד אופליין מלא, מקבצים מקומיים. לכל פרט יש מקור ותאריך בדיקה, או סימון ברור "טרם אומת".

## החלטות של בעל המוצר (2026-11-22)
- **הכרטיס בבית:** "מסמכים" הוחלף ב"מידע וחירום". נוסף כפתור "חירום" נפרד בבית.
- **כפתור החירום:** מציג רק מספרי חירום מאומתים.
- **קישור למפה:** נבנה רק מכתובת או קואורדינטות מאומתות, ונפתח רק בלחיצה (דרך `mapsSearchUrl`, החריגה הקיימת בכלל 5).
- **הצ'ק-ליסט:** הפריט "מספרי חירום" עודכן לנתונים המאומתים ומפנה למסך.
- **גרסה 0.10.0.** PR אחד עכשיו, ו-PR קטן אחרי אישור המסלול ב-29.11 (שלב ד).

## מה נבנה
- **נתונים:** `data/info/th.json`. ארבעה סטטוסים: `verified-official`, `user-provided`, `unverified`, `hidden`. לפרט שטרם אומת אין ערך בקובץ.
- **ליבה:** `src/js/core/info.js` (אימות הקובץ, רק מספרים מאומתים לחירום, `tel:`, קישור מפה, הערות).
- **מסך:** `src/js/info-view.js` (`#/info`). הכרטיס "מידע וחירום" וכפתור "חירום" בבית. בתי החולים מקופלים, וכפתור החיוג נשאר בחוץ.
- **הערות:** `trip.info.notes`. נשמרות דרך `storage.js` ונכנסות לגיבוי. בלי שינוי סכמה.
- **אופליין:** שלושת הקבצים החדשים ב-`PRECACHE` של `sw.js`.

- **תאית וכללי התנהגות:** לא נמצא מקור אמין שנבדק, ולכן מוסתרים.
- **קישור לחיץ למקור:** המקור מוצג כטקסט. קישור לחיץ החוצה צריך אישור (כלל 5).
